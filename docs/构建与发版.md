# 构建与发版

## 环境

| 依赖 | 说明 |
| --- | --- |
| DevEco Studio | HarmonyOS NEXT（5.x），自带 hvigor 与 ohpm |
| HarmonyOS SDK | API 12（`5.0.0(12)`），工程 `build-profile.json5` 的 `compatibleSdkVersion` 可调高 |
| 设备 | 鸿蒙手机 / 平板 / 2in1，或模拟器 |
| 运行依赖 | 局域网内可访问的 FnReader 服务端（端口默认 1122） |

> 本仓库**不含**签名证书。鸿蒙调试运行可用 DevEco 自动生成的临时签名；发布 HAP 需要你自己的 `.p12` / `.cer` / `.p7b`，不要把它们提交进仓库。

## 在 DevEco Studio 里跑

1. `File → Open` 选择本仓库根目录
2. 等待 hvigor sync（首次会下载 `@ohos/hvigor-ohos-plugin`、`@ohos/hypium`）
3. `Project Structure → Signing Configs` 勾选自动签名
4. 连接设备，`Run 'entry'`

## 命令行构建

用 DevEco Studio 自带的 hvigor 包装器（Windows 为 `hvigorw.bat`，需在 `hvigor` 目录或 PATH 中）：

```bash
# 清理
hvigorw clean --no-daemon

# 打 debug HAP
hvigorw assembleHap --mode module -p product=default -p buildMode=debug --no-daemon

# 打 release HAP（需先配好 signingConfigs）
hvigorw assembleHap --mode module -p product=default -p buildMode=release --no-daemon
```

产物：

```
entry/build/default/outputs/default/entry-default-signed.hap     # 已签名，可安装
entry/build/default/outputs/default/entry-default-unsigned.hap   # 未签名
```

安装到设备：

```bash
hdc install entry/build/default/outputs/default/entry-default-signed.hap
hdc shell aa start -a EntryAbility -b io.github.tzylxs.yuedu
```

## 版本号

两处必须同步：

- `AppScope/app.json5`：`versionCode`（整数，递增）、`versionName`
- `oh-package.json5` 与 `entry/oh-package.json5`：`version`

## 发版流程

```bash
# 1. 改版本号与 CHANGELOG.md，跑一次构建确认能编译
# 2. 提交并打 tag
git add -A
git commit -m "release: vX.Y.Z"
git tag -a vX.Y.Z -m "vX.Y.Z"
git push origin main --tags

# 3. 打源码包
git archive --format=zip --prefix=yuedu-harmony-X.Y.Z/ -o yuedu-harmony-X.Y.Z-source.zip vX.Y.Z

# 4. 建 Release 并挂 asset（REST API 或 gh CLI）
gh release create vX.Y.Z --title "vX.Y.Z" --notes-file RELEASE_NOTES.md \
  yuedu-harmony-X.Y.Z-source.zip
```

有 HAP 时一并上传：

```bash
gh release upload vX.Y.Z entry-default-signed.hap
```

## 已知约束

- 标准 GitHub 托管 runner 没有 HarmonyOS SDK，**不能**直接 CI 编译 HAP；需要自建 runner 或本地 DevEco 出包
- `dist/`、`*.hap`、`*.har` 已在 `.gitignore` 中忽略，构建产物不进仓库
- 本工程在无 HarmonyOS SDK 的机器上生成，首次 sync 若提示 `compatibleSdkVersion` 不匹配，按 DevEco 提示改为本机已安装的 API 版本即可
