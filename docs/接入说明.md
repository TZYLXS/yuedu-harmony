# 接入说明

服务端为 [FnReader](https://github.com/TZYLXS/FnReader)（飞牛 fnOS 上的「阅读」）。默认地址 `http://<NAS IP>:1122`，所有移动接口都要求访问令牌。

令牌在服务端「设置 → 手机接入」查看，也可重置（`POST /api/m/reset-token`）。客户端把它存在本地 Preferences，WebDAV 与书源桥复用同一个令牌。

---

## 一、手机接入 API（`/api/m/*`）

鉴权二选一：

```
X-Api-Token: <token>
```
或
```
/api/m/shelf?token=<token>
```

| 方法 | 路径 | 返回要点 |
| --- | --- | --- |
| GET | `/api/m/info` | `{ app, version, tokenRequired, endpoints[] }`，用来验证地址与令牌 |
| GET | `/api/m/shelf` | `{ books: ShelfBook[] }`，按 `durChapterTime` 倒序 |
| GET | `/api/m/search?key=&group=&limit=` | `{ key, books: ShelfBook[] }`，默认 8 个已启用且检测通过的书源，最多 30 |
| GET | `/api/m/toc?url=<bookUrl>` | `{ name, author, chapters: [{index,title,url}] }`；书不在书架返回 404 |
| GET | `/api/m/content?url=<bookUrl>&index=<n>` | `{ bookUrl,title,index,total,prev,next,paragraphs[],cached }` |
| POST | `/api/m/progress` | body `{bookUrl,index,pos,title}` → `{ok:true}` |
| GET | `/api/m/cover?url=<bookUrl>` | 图片二进制，服务端代理并处理防盗链 |
| POST | `/api/m/reset-token` | 重置令牌 |
| GET | `/api/m/booksource?token=` | Legado 书源 JSON（见下节） |

`ShelfBook` 字段（服务端 `mobileBook()` 原样返回）：

```json
{
  "bookUrl": "...", "name": "...", "author": "...", "coverUrl": "...",
  "intro": "...", "kind": "...", "origin": "...", "originName": "...",
  "lastChapter": "...", "durChapterIndex": 0, "durChapterPos": 0,
  "durChapterTitle": "...", "durChapterTime": 0, "totalChapterNum": 50
}
```

示例：

```bash
BASE="http://192.168.1.10:1122"; TOKEN="<令牌>"
curl -H "X-Api-Token: $TOKEN" "$BASE/api/m/info"
curl -H "X-Api-Token: $TOKEN" "$BASE/api/m/shelf"
curl -H "X-Api-Token: $TOKEN" "$BASE/api/m/content?url=<bookUrl>&index=0"

curl -X POST -H "X-Api-Token: $TOKEN" -H "Content-Type: application/json" \
  -d '{"bookUrl":"<bookUrl>","index":3,"pos":0,"title":"第3章"}' \
  "$BASE/api/m/progress"
```

客户端实现：`entry/src/main/ets/common/ApiClient.ets`（统一 10s 连接 / 30s 读超时，非 200 时把服务端 `error` 字段透出）。

## 二、Legado 书源桥

不修改「阅读」APK，由服务端生成一份书源，把搜索 / 详情 / 目录 / 正文映射回自己：

| 步骤 | 地址 |
| --- | --- |
| 书源 JSON | `GET /api/m/booksource?token=<token>` |
| 导入链接 | `legado://import/bookSource?src=<书源 JSON 地址，URL 编码>` |
| 搜索 | `GET /api/m/legado/search?key=&page=` → `{books:[{name,author,kind,intro,lastChapter,coverUrl,bookUrl}]}` |
| 详情 | `GET /api/m/legado/book?u=<b64url(bookUrl)>&s=<b64url(书源地址)>&n=<书名>`，不在书架会自动入架（`addedBy: "apk"`） |
| 目录 | `GET /api/m/legado/toc?u=<b64url(bookUrl)>`，章节 `url` 直接指向 `/api/m/content` |
| 正文 | 复用 `GET /api/m/content`，规则取 `$.paragraphs[*]` |

`legado://` 规则：`legado://import/{path}?src={url}`，`path=bookSource` 表示书源；`src` 必须做 URL 编码（`encodeURIComponent`）。

客户端实现：`LegadoBridge.ets`。它会按当前配置生成两段可直接复制的文本：

```
书源 JSON  http://<NAS>:1122/api/m/booksource?token=<token>
导入链接   legado://import/bookSource?src=http%3A%2F%2F<NAS>%3A1122%2Fapi%2Fm%2Fbooksource%3Ftoken%3D<token>
```

落地方式：老安卓（4.4–5.1）装 [yuedu-android4](https://github.com/TZYLXS/yuedu-android4)，在「阅读」里选**网络导入**，粘贴 `legado://` 链接。

> 令牌含 `+ / =` 等字符时，务必让客户端做编码，手拼链接最容易在这里出错。

## 三、WebDAV

| 路径 | 权限 | 内容 |
| --- | --- | --- |
| `/dav/` | 入口 | 用户名任意，密码=访问令牌 |
| `/dav/books/` | 只读 | 书架里已下载的 `.txt` |
| `/dav/backup/` | 读写 | 给「阅读」的备份与恢复用 |

```
地址：http://<NAS IP>:1122/dav/
用户名：任意（如 yuedu）
密码：<访问令牌>
```

用法：
- 文件管理器（Solid Explorer / ES / 群晖 DS file 等）添加 WebDAV 服务器，直接浏览 `/dav/books/`
- 「阅读」→ 备份与恢复 → WebDAV，填上面的地址与密码

客户端实现：`WebDavHelper.ets`，只负责生成地址与提示；WebDAV 客户端请在系统文件管理器或「阅读」里使用。

## 排错

| 现象 | 排查 |
| --- | --- |
| 连接失败 / 401 | 令牌是否复制完整；服务端是否重置过令牌；地址端口是否 1122 |
| 书架空 | 服务端书架本身为空，先在飞牛「阅读」里加书 |
| 目录 / 正文 404 | 书不在书架中（`/api/m/toc`、`/api/m/content` 都要求 bookUrl 已在书架） |
| 封面裂图 | 用 `/api/m/cover?token=..&url=..`；直连源站封面会被防盗链挡住 |
| `legado://` 导入失败 | `src` 未编码或链接被聊天软件截断；重新复制完整链接 |
| 局域网连不上 | 手机与 NAS 不同网段；NAS 防火墙未放行 1122；应用未授予网络权限 |
